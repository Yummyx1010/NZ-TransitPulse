## 4. Route context

Added a global `RouteContextProvider` in `AppShell`.

The URL is the source of truth:

```text
?route=70
```

The context resolves:

- `routeNo`: official AT route number used in reports
- `routeId`: primary GTFS `route_id`
- `routeIds`: all matching GTFS route IDs
- `routeLabel`: resolved display label
- `matchedInGtfs`: whether a GTFS match exists

`AnalyticsFilterProvider` now reuses this route context instead of maintaining a separate
route parameter. Selecting a route in one analytics view carries into other views.

## 5. Business semantics preserved

- `Most used routes` ranks ridership descending.
- `Routes requiring attention` ranks punctuality/reliability ascending.
- Ridership is not described as operational performance.
- Official punctuality/reliability values are shown with `%` units.
- Boardings are shown with passenger-trip units.
- Source coverage and compatibility warnings remain attached to analytics responses.
- No synthetic targets or filled missing values were introduced.
