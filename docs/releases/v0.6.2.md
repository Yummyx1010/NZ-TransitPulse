# v0.6.2 — Global Visual Redesign

- **Date:** 2026-11-21
- **Scope:** Design system, navigation, typography, layout, maps and chart styling
- **Status:** Complete, not committed

## 1. Goal

Upgrade NZ TransitPulse from a functional dashboard into a coherent transport
intelligence product with a distinctive civic-data identity. This milestone changes the
visual layer only; business calculations, APIs, database schema and ingestion are
unchanged.

## 2. Design direction

The visual language is a **light transport observatory**:

- warm off-white canvas `#F7F7F4`
- white surfaces `#FFFFFF`
- deep charcoal type `#202B31`
- restrained forest-green primary `#25685F`
- amber semantic warning `#C58B45`
- ridership blue `#426F9C`
- relationship terracotta `#A15F3E`
- low-chroma borders and hairline dividers
- no gradients, no oversized card stacks, no heavy navy sidebar

Typography uses an editorial hierarchy with `Avenir Next` / `Inter` style system fonts,
tabular numerals for metrics, and tighter letter spacing for page titles.

## 3. What changed

### Global shell

- narrow warm sidebar with numbered primary modules
- grouped navigation: Explore / Analytics / Reference / Planned
- active state uses a forest-green left rule and soft green surface
- brand mark redesigned as a compact transit glyph
- sidebar grid texture adds quiet transport-map character
- keyboard skip link to main content
- semantic `<main id="main-content">` wrapper
- mobile horizontal navigation with accessible labels

### Pages and components

- consistent page header with short accent rule
- compact metric strip
- flatter panels with light hover feedback
- restrained chart panels and legends
- improved controls and focus states
- improved empty, loading and warning states
- responsive breakpoints for map, rankings and passenger board
- `prefers-reduced-motion` support

### Live Network

- route geometry changed to forest green
- stop markers use ridership blue
- bus markers remain warm orange for high visibility
- map panel, legend, ETA board and route list now share the global design tokens
- map height and layout behave better on smaller screens

### Analytics charts

- semantic chart classes:
  - ridership: blue
  - punctuality/reliability: green
  - relationships: terracotta
- attention bars use amber
- heatmap uses a sequential green palette
- chart points have subtle transitions and clear selected states
